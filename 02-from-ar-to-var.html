4  From AR to VAR

4.1 How to trace the dynamic effect of a shock?

Recursive substitution, the dynamic multiplier, and the Wold representation (infinite moving-average) are usually taught as separate topics. They are not: they are three views of a single question, how does a shock propagate through time? The answer comes first in the scalar AR(1) world, where every step is intuitive and easy to understamd, and is then replayed the same argument in the matrix VAR world, where the algebra is heavier but the logic is identical. The reward is a clean bridge: the moving-average weights, the dynamic multipliers and the impulse responses are the same object.

3 key definition:

  1. Recursive substitution: unwinding the model until \(y_t\) is written in terms of past shocks.
  2. Dynamic multiplier: the effect of one shock, horizon by horizon. This is the impulse response.
  3. Wold representation: under stationarity assumption the influence of the initial value fades to zero and only the shock sum survives. The moving-average form has as coefficients the multipliers of point 2.

4.2 Part A - The scalar case: AR(1)

4.2.1 Recursive substitution

Starting with a first-order autoregressive process (to keep it simple the constant is dropped — no worries, it would only have shifted the mean), with \(\varepsilon_t\) a white-noise shock:

\[ y_t = \phi\, y_{t-1} + \varepsilon_t, \qquad \varepsilon_t \sim \text{WN}(0,\sigma^2) \tag{4.1}\]

The recursion can be run backward. Start from \(y_t\) and substitute its own equation into itself: replacing \(y_{t-1}\) introduces \(y_{t-2}\), replacing \(y_{t-2}\) introduces \(y_{t-3}\), and so on. Each substitution peels off one more shock and raises the power of \(\phi\) by one, walking the index down until it reaches the initial value \(y_{-1}\):

\[ \begin{aligned} y_t &= \phi\, y_{t-1} + \varepsilon_t \\ &= \phi\,(\phi\, y_{t-2} + \varepsilon_{t-1}) + \varepsilon_t = \phi^{2} y_{t-2} + \phi\,\varepsilon_{t-1} + \varepsilon_t \\ &= \phi^{2}(\phi\, y_{t-3} + \varepsilon_{t-2}) + \phi\,\varepsilon_{t-1} + \varepsilon_t = \phi^{3} y_{t-3} + \phi^{2}\varepsilon_{t-2} + \phi\,\varepsilon_{t-1} + \varepsilon_t \\ &\;\;\vdots \\ &= \phi^{\,t+1} y_{-1} + \phi^{\,t}\varepsilon_0 + \cdots + \phi\,\varepsilon_{t-1} + \varepsilon_t \end{aligned} \tag{4.2}\]

Collecting the terms gives the general solution:

\[ y_t = \phi^{\,t+1} y_{-1} + \sum_{i=0}^{t} \phi^{\,i}\, \varepsilon_{t-i} = \phi^{\,t+1} y_{-1} + \varepsilon_t + \phi\, \varepsilon_{t-1} + \cdots + \phi^{\,t} \varepsilon_0 \tag{4.3}\]

The value of \(y_t\) splits into two pieces: a transient \(\phi^{\,t+1} y_{-1}\) carried by the initial condition, and a weighted sum of every shock since the start, with weight \(\phi^{\,i}\) on the shock \(i\) periods ago.

4.2.2 The dynamic multiplier = the impulse response

Because Equation 4.3 writes \(y_t\) as a linear function of the shocks, the effect of a single shock is read off directly. Restarting the count at an arbitrary date \(t\):

\[ y_{t+j} = \phi^{\,j+1} y_{t-1} + \sum_{i=0}^{j}\phi^{\,i}\, w_{t+j-i} \tag{4.4}\]

and differentiating with respect to the shock \(w_t\):

\[ \frac{\partial\, y_{t+j}}{\partial\, w_t} = \phi^{\,j} \tag{4.5}\]

This quantity — the dynamic multiplier — is the response of \(y\), \(j\) periods ahead, to a one-unit shock today. Two features matter. First, it depends only on the horizon \(j\), not on the date \(t\): the system reacts to a shock the same way no matter when it lands. Second, this is exactly an impulse-response function — trace \(\phi^{\,j}\) for \(j = 0, 1, 2, \dots\) and you have drawn the system’s response to an impulse.

The shape depends entirely on \(\phi\):

  • \(0<\phi<1\): monotone geometric decay toward zero;
  • \(-1<\phi<0\): decay with alternating sign (damped oscillation);
  • \(\phi>1\): explosive monotone growth;
  • \(\phi<-1\): explosive oscillation.

The dividing line is \(|\phi|<1\): inside it a shock’s effect eventually dies out and the system is stable; outside it the effect grows without bound. The borderline \(\phi=1\) is the random walk, where \(\phi^{\,j}=1\) for every \(j\) and a shock’s effect is permanent.

Move the slider through all four regimes — this is the response \(\partial y_{t+j}/\partial w_t = \phi^{\,j}\):

viewof phi = Inputs.range([-1.2, 1.2], {value: 0.8, step: 0.05, label: "phi"})
{
  const H = 20;
  const data = d3.range(0, H + 1).map(j => ({j, resp: Math.pow(phi, j)}));
  return Plot.plot({
    height: 300,
    marginLeft: 55,
    x: { label: "horizon j" },
    y: { label: "response = phi^j", grid: true },
    marks: [
      Plot.ruleY([0]),
      Plot.barY(data, { x: "j", y: "resp",
        fill: d => d.resp >= 0 ? "#4c78a8" : "#e45756" })
    ]
  });
}

4.2.3 From recursive substitution to the Wold representation

Now let the process have been running not from date \(-1\) but from the infinite past — equivalently, let \(t\to\infty\) in Equation 4.3. When \(|\phi|<1\) the transient vanishes, \(\phi^{\,t+1} y_{-1}\to 0\), and only the shock sum survives:

\[ y_t = \sum_{i=0}^{\infty}\phi^{\,i}\, w_{t-i} = w_t + \phi\, w_{t-1} + \phi^{2} w_{t-2} + \cdots \tag{4.6}\]

This is the MA(\(\infty\)), or Wold, representation: the current value \(y_t\) as a weighted sum of all past shocks. It is nothing more than recursive substitution pushed to its limit under stationarity — and its weights \(\phi^{\,i}\) are exactly the dynamic multipliers of Equation 4.5.

The same object is reached algebraically with the lag operator \(L\) (with \(L\,w_t = w_{t-1}\)): writing Equation 4.1 as \((1-\phi L)\,y_t = w_t\) and inverting,1

\[ y_t = \frac{w_t}{1-\phi L} = \Big(\sum_{i=0}^{\infty}\phi^{\,i} L^{i}\Big) w_t, \tag{4.7}\]

which reproduces Equation 4.6 term by term. The geometric series converges for exactly the reason the transient dies: \(|\phi|<1\).

4.3 Part B — The matrix case: VAR(p)

Everything above now repeats with one substitution: scalars become matrices. Nothing in the logic changes.

4.3.1 Recursive substitution for the VAR

The reduced-form VAR(1) (again dropping the constant) is the matrix twin of Equation 4.1, with \(Z_t\) stacking the \(n\) variables, \(\Phi\) an \(n\times n\) coefficient matrix, and \(w_t\) the vector of innovations:

\[ Z_t = \Phi\, Z_{t-1} + w_t \tag{4.8}\]

Substituting exactly as before — every \(\phi^{\,i}\) becoming \(\Phi^{\,i}\):

\[ Z_t = \Phi^{\,t+1} Z_{-1} + \sum_{i=0}^{t}\Phi^{\,i}\, w_{t-i} \tag{4.9}\]

Same structure as Equation 4.3: a transient \(\Phi^{\,t+1} Z_{-1}\) plus a weighted sum of past shock vectors, now with matrix weights \(\Phi^{\,i}\).

4.3.2 The VMA(\(\infty\)): the multivariate Wold representation

Letting the process run from the infinite past, if the VAR is stationary the transient dies, \(\Phi^{\,t+1} Z_{-1}\to 0\),2 and

\[ Z_t = \sum_{i=0}^{\infty}\Phi^{\,i}\, w_{t-i} = \sum_{i=0}^{\infty}\Psi_i\, w_{t-i}, \qquad \Psi_i = \Phi^{\,i},\;\; \Psi_0 = I_n \tag{4.10}\]

This is the VMA(\(\infty\)), the multivariate Wold representation. For a VAR(1) the moving-average matrices are simply the powers \(\Psi_i=\Phi^{\,i}\) — the literal analogue of the scalar \(\phi^{\,i}\). For a general VAR(\(p\)) the same object is obtained with the lag operator: writing the model as \(G(L)\,Z_t = w_t\) and inverting the matrix polynomial,

\[ Z_t = \mu + G(L)^{-1} w_t = \mu + \sum_{i=0}^{\infty}\Psi_i\, w_{t-i}, \tag{4.11}\]

where the \(\Psi_i\) are the coefficient matrices of the power series \(G(L)^{-1}=\sum_i \Psi_i L^{i}\) (with \(\Psi_0=I_n\)), and \(\mu\) is the mean, restored once the constant is put back.

The parallel with the scalar case is one-to-one:

AR(1) — scalar VAR(p) — matrix
dynamic equation \(y_t=\phi\, y_{t-1}+w_t\) \(Z_t=\Phi\, Z_{t-1}+w_t\)
recursive substitution \(y_t=\phi^{\,t+1}y_{-1}+\sum_i \phi^{\,i} w_{t-i}\) \(Z_t=\Phi^{\,t+1}Z_{-1}+\sum_i \Phi^{\,i} w_{t-i}\)
MA weight \(\phi^{\,i}\) \(\Psi_i\;\;(=\Phi^{\,i}\text{ if }p=1)\)
representation MA(\(\infty\)) VMA(\(\infty\))
stationarity \(\lvert\phi\rvert<1\) roots of \(\det G(L)=0\) outside the unit circle
multiplier \(=\) IRF \(\partial y_{t+j}/\partial w_t=\phi^{\,j}\) \(\partial Z_{t+j}/\partial w_t'=\Psi_j\)

4.3.3 The multiplier becomes the impulse response

Differentiating Equation 4.11 with respect to the shock vector, exactly as in the scalar case:

\[ \frac{\partial\, Z_{t+j}}{\partial\, w_t'} = \Psi_j \tag{4.12}\]

Each matrix \(\Psi_j\) is the system’s response, \(j\) periods ahead, to a one-unit impulse in the shocks: its \((k,\ell)\) entry is the reaction of variable \(k\) to a shock in variable \(\ell\). Where the scalar multiplier \(\phi^{\,j}\) traced a single decaying (or oscillating, or explosive) path, \(\Psi_j\) now carries both own- and cross-effects, so responses can travel between variables, oscillate, and feed back through the system before dying out — the feedback loop of the previous chapter, made quantitative.

For a bivariate VAR(1) this is a \(2\times2\) grid: each variable’s reaction to each shock. The sliders are the four entries of \(\Phi\); each panel traces an entry of \(\Psi_j=\Phi^{\,j}\) over the horizon \(j\):

viewof phi11 = Inputs.range([-0.95, 0.95], {value: 0.5, step: 0.05, label: "Phi 1,1 (x on own lag)"})
viewof phi12 = Inputs.range([-0.95, 0.95], {value: 0.3, step: 0.05, label: "Phi 1,2 (x on lagged y)"})
viewof phi21 = Inputs.range([-0.95, 0.95], {value: 0.2, step: 0.05, label: "Phi 2,1 (y on lagged x)"})
viewof phi22 = Inputs.range([-0.95, 0.95], {value: 0.5, step: 0.05, label: "Phi 2,2 (y on own lag)"})
{
  const H = 20;
  const Phi = [[phi11, phi12], [phi21, phi22]];
  const mul = (A, B) => [
    [A[0][0]*B[0][0] + A[0][1]*B[1][0], A[0][0]*B[0][1] + A[0][1]*B[1][1]],
    [A[1][0]*B[0][0] + A[1][1]*B[1][0], A[1][0]*B[0][1] + A[1][1]*B[1][1]]
  ];
  const vars = ["x", "y"];
  let Psi = [[1, 0], [0, 1]];
  const rows = [];
  for (let j = 0; j <= H; j++) {
    for (let k = 0; k < 2; k++) {
      for (let l = 0; l < 2; l++) {
        rows.push({
          j,
          resp: Psi[k][l],
          respVar: "response of " + vars[k],
          shockVar: "shock to " + vars[l]
        });
      }
    }
    Psi = mul(Phi, Psi);
  }
  return Plot.plot({
    height: 380,
    marginLeft: 55,
    x: { label: "horizon j" },
    y: { label: "response", grid: true },
    fx: { label: null },
    fy: { label: null },
    marks: [
      Plot.ruleY([0]),
      Plot.barY(rows, {
        x: "j",
        y: "resp",
        fx: "shockVar",
        fy: "respVar",
        fill: d => d.resp >= 0 ? "#4c78a8" : "#e45756"
      })
    ]
  });
}

Try pushing the coefficients up: some combinations put a root of \(\det G(L)\) inside the unit circle and the responses explode instead of dying out — nonstationarity, made visible.

4.3.4 Where this leads

These \(\Psi_j\) are the reduced-form impulse responses: they answer “what happens if the reduced-form innovation \(w_{\ell t}\) moves by one unit?” But the innovations are correlated across equations, so a shock to one variable rarely arrives in isolation — which makes the reduced-form responses hard to read as clean economic experiments. Recovering structural impulse responses, where the shocks are mutually uncorrelated and interpretable, requires identifying the VAR — orthogonalizing the innovations. That is the subject of the next chapter, together with the forecast error variance decomposition, which uses these very same \(\Psi_j\) to split forecast uncertainty across shocks.

  1. The inversion of \((1-\phi L)\) in Equation 4.7 is a geometric series \(\sum_i \phi^{i} L^{i}\) that converges only when \(|\phi| < 1\). If \(|\phi| \ge 1\) the weights do not decay, the sum of past shocks diverges, and no stable MA(\(\infty\)) exists — the process is nonstationary (the random walk \(\phi = 1\) is the borderline case).

    For the VAR the requirement is the same in spirit but heavier to state: \(G(L)^{-1}\) exists as a convergent power series only if \(G(L)\) is invertible, which holds if and only if all \(np\) roots of

    \[\det\!\left(I_n - G_1 L - G_2 L^{2} - \cdots - G_p L^{p}\right) = 0\]

    lie outside the unit circle — equivalently, the inverse roots (the eigenvalues of the companion matrix) lie inside it. It is the exact matrix generalization of \(|\phi| < 1\): one condition on a single scalar becomes a condition on the modulus of every root of a matrix polynomial.↩︎

  2. The inversion of \((1-\phi L)\) in Equation 4.7 is a geometric series \(\sum_i \phi^{i} L^{i}\) that converges only when \(|\phi| < 1\). If \(|\phi| \ge 1\) the weights do not decay, the sum of past shocks diverges, and no stable MA(\(\infty\)) exists — the process is nonstationary (the random walk \(\phi = 1\) is the borderline case).
